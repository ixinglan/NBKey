# NBKey v1.0.0

macOS 菜单栏快捷键映射工具。在系统快捷键之上再加一层自定义组合 —— 用键盘组合、鼠标组合，
去触发系统级操作。

首个正式版本，核心能力是**切换桌面**：把 `⌃ + 鼠标左键 / 右键` 映射到系统原生的三指横滑手势管线，
因此切换带动画、支持台前调度，与你手动在触控板上滑动完全等价。

---

## 系统要求

- macOS 14.0 (Sonoma) 或更高
- 通用二进制，Apple Silicon 与 Intel 均可用

## 安装

1. 下载 `NBKey-1.0.0.dmg`
2. 打开 DMG，把 **NBKey.app** 拖进「应用程序」
3. 首次运行时按提示授权：**系统设置 › 隐私与安全性 › 辅助功能** → 勾选 NBKey

第 3 步是必须的。macOS 不允许任何应用在没有这个权限的情况下拦截全局按键 / 鼠标事件，
未授权时 NBKey 会显示未授权状态，不拦截任何事件。

授权后回到 NBKey 设置窗口会自动重试启动引擎，不需要重启应用。

## 如果提示「无法验证开发者」

本版本已用 Developer ID 签名并完成 Apple 公证，正常情况双击即可打开。

如果你是自行构建、或拿到的是未公证的构建，macOS 会拦住它。处理办法：

```bash
# 把 app 拖进「应用程序」后执行
xattr -dr com.apple.quarantine /Applications/NBKey.app
```

或在「应用程序」里按住 Control 点击 NBKey → 选「打开」→ 弹窗里再点一次「打开」。

## 校验下载完整性

每个 DMG 都附了 SHA256 文件：

```bash
shasum -a 256 -c NBKey-1.0.0.dmg.sha256
```

## 功能

| 能力 | 说明 |
| --- | --- |
| 自定义触发组合 | 键盘组合（任意键 + ⌃⌥⇧⌘fn）或鼠标组合（左/右/中/侧键 + 修饰键），也可直接录制 |
| 触发 → 系统操作 | 命中后执行系统快捷键；`⌃←` / `⌃→` 会被识别为「切换桌面」，走系统原生手势管线 |
| 多显示器 | 按**鼠标所在显示器**切换空间 |
| 规则管理 | 逐条启用 / 停用，重复的触发组合会标红提示 |
| 深色模式 | 界面跟随系统外观，无需单独设置 |
| 应用快捷键 | `⌘,` 打开设置、`⌘N` 新增规则、`⌘W` 关闭窗口、`⌘Q` 退出 |

配置示例、界面导览与实现原理见仓库 [README](../../README.md)。

## 已知限制

- 动作目标键限定在常用系统键集合内（方向键 / F1–F12 / Esc / Tab / Return / Home / End / 翻页键等），
  暂不支持映射到字母数字键。
- 「切换桌面」依赖系统「调度中心 › 在活动空间之间移动」仍是 `⌃←` / `⌃→` 的默认绑定。
- 使用了 WindowServer 的私有接口（Dock 手势字段编号、SkyLight 的 CGS 接口），
  **不能上架 App Store**，系统大版本升级后需要重新验证。
- 签名方式变更（例如从自行构建的开发签名换成正式版签名）后，需要重新授予辅助功能权限 ——
  macOS 的权限是跟签名绑定的。

## 可复现构建

产物由 GitHub Actions 在 `macos-26` runner（Xcode 26.6）上构建，你也可以本地复现同一套流程：

```bash
./scripts/build-release.sh 1.0.0 ./dist
```

脚本会把构建、签名、公证、打包 DMG、校验串成一条链，任一步失败即中止。
